# M10: Rust production без C++ oracle

Пользователь отдельно разрешил M10 после исправления завершения вывода. M9
закрыл live cutover; его использованный бюджет не разрешает новые model calls.
Этот этап не меняет runtime semantics, v1 schemas, зависимости или UX.

## Обязательный inventory

- Locked Cargo workspace tests, включая doctests и все native/property/parity
  assertions. Protocol, auth и session читают committed synthetic/golden data.
  Runtime проверяет unknown/unresolved restart, late known outcomes и отмену;
  process suites запускают и убирают собственных реальных потомков.
- fmt и clippy по всем targets/features; сборка всех fixture adapters.
- `tests/replay_mutation.py`: неизменённый production builder проходит тест;
  drop/reorder mutants обязаны упасть на соответствующих replay assertions.
  Ошибка компиляции, timeout и другой failure не считаются killed mutant.
- Default Nix package и `nix flake check` из свежего checkout без C++ source,
  CMake cache, oracles или target directory. Nix caches разрешены; это проверка
  чистых source inputs, а не утверждение о cold dependency cache. Повторный
  Cargo `--offline` допустим только после явного заполнения dependency cache.
- Production installed `ansa --self-check` и `--offline-demo`.
- `tests/rust_acceptance.py`: ровно **12** сценариев. Readonly reopen
  committed C++ v1 CLI journal с исходным transcript и неизменными part bytes;
  synthetic access/refresh/nonce canaries в stdout/stderr/journal и auth-status;
  семь I/O faults (accepted-fsync cancel, signal cancel, read error, unread stderr,
  EPIPE, blocked stdout cancel/shutdown); три continuous TTY flood с адресным
  Cancel, canonical trace и восстановлением terminal state.
- `tests/cli_progress_pty.py`: **10** сценариев, включая чтение/черновик, recall,
  copy, preview/tools, SIGTERM/SIGHUP в paused session и termios/FD restoration.
- `tests/carbon_workspace_pty.py`: **20** сценариев в Debug и установленном
  Release. Среди них мышиная прокрутка с сохранением позиции при вводе/отправке,
  slash completion/help, model→effort, сохранённые названия и дерево агентов,
  persistent terminal и его Ctrl+C/Esc/EOF, Source/Markdown, инструменты и копирование.
- `tests/editor_setup_pty.py`: **2** сценария в обоих профилях: открытие редактора
  при заблокированном выводе и отмена подготовки.
- `tests/carbon_visual_pty.py`: **3** цветных сценария в обоих профилях:
  жизненный цикл инструментов, выделение и resize; предпросмотр, отмена и
  сохранение темы, custom/Auto DMS; реальный `edit_file` с точным inline diff.
  Сценарий редактирования использует adapter соответствующего build profile
  с production runtime/tools/workbench. **3** контрольных примера проверяют
  независимый VT oracle фактических цветов и подложек.
- `tests/cli_output_drain.py`: **4** сценария, включая полный медленный вывод,
  остановку без прогресса и прерывание. Canonical Done/outcomes проверяются отдельно.
- `tests/cli_live_startup.py --repeat 256`: **259** synthetic запусков, включая
  expired idle без сети до Submit и отмену auth preparation.
- Pinned nightly ASan с instrumented std/leak detection по полному native corpus.
  TSan/Miri/UBSan или другая неподдерживаемая проверка не становятся PASS.
- Native independent review до финальной тяжёлой матрицы; проверенный checkpoint,
  результаты, ограничения и следующий шаг в PROJECT_STATE.

Все gates используют production Rust builders/runtime/tools/frontend. Cargo
сборки выполняются последовательно с `CARGO_BUILD_JOBS=2`; число jobs Nix builder
фиксируется отдельно. PTY/fault acceptance получает отдельное окно.
Пустой, skipped, dirty или неполный required capture - FAIL.
Команды находятся в [README](../../README.md).

## Historical comparisons и rollback

C++ code tag: `migration/m9-cutover`, source
`742d29cae55cfd993d3ce817962fbabdcccb6a99`. Проверенный executable и Nix GC root:
`~/Workspace/pet/ansa-baselines/m9-742d29c/{ansa-cpp,cpp-package}`. ELF SHA-256:
`420c80f7e7b9787e1b6eba18097f0ec97d3b25cc11630b4b0f1a840f88206ff0`.
Дополнительный root прежней установленной C++ версии сохранён в
`~/Workspace/pet/ansa-baselines/carbon-c5534d3/cpp-before-m10`.

`tests/fixtures/sessions/cli-cpp-v1/manifest.json` связывает readonly CLI golden
с source tag, executable hash, canonical record inventory, transcript и part
hashes. Fixture создан один раз до удаления C++; обязательный gate его читает
без C++ binary. Предыдущие bidirectional migration captures сохраняются отдельно.

Исторический `tests/parity/run.py` явно отказывает в новом differential capture
без pre-M10 checkout. Performance selector не может выдать Rust default за C++:
он требует explicit C++ package либо старую проверяемую CMake derivation.
Результаты исторических C++ captures не объявляются заново PASS на новом SHA.

При откате запускается сохранённый C++ с наиболее свежим совместимым state.
Старые credentials/journal не восстанавливаются после rotation/side effects.
Если state несовместим, dispatch останавливается до явного восстановления.
Исправление `encrypted_content` в P1 не перенесено в frozen C++: новый допустимый
промежуточный reasoning envelope он может отклонить. Финальные v1 данные сохранены.

Cargo workspace остаётся в `rust/`. Python нужен только test harness; runtime
не запускает Python/C++ helpers. C/assembly toolchain для ring и системный
libgcc unwinder остаются обычными Rust build/runtime dependencies.
