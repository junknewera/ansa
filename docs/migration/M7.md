## Изменение

Rust executable теперь соединяет M4 session catalog, M5 runtime и M6 tools с
настоящими one-shot, pipe, interactive и JSONL frontend. Сохранены legacy flags,
help, exit codes, stdout/stderr и v1 wire schema. Help и private worker dispatch
выполняются до Tokio/auth/bootstrap. Auth и provider используют существующие
кодеки и admission; HTTPS bridge ограничивает headers, body, trailers и wire
overhead, требует успешный EOF и не повторяет ambiguous POST.

Carbon работает в основном terminal buffer. Есть первая history page до input,
basic/plan, Tab/Shift+Tab, slash commands, Ctrl+F, PgUp/PgDn, resize, transient
preview и resync. Draft сохраняется до admission, при busy/rejection и overflow.
Повторная отмена не оставляет frontend в cancelled state для следующего turn.
Invalid или cancelled preview не записывается в canonical journal.

Output worker имеет bounded queue и один coalesced frame. Control owner не
ждёт stdout/stderr: обычный drain ограничен 250 ms, после чего writer прерывается
и join выполняется с ненулевым результатом CLI. Это ограничение writer, а не
обещание абсолютного времени всего journal/process cleanup. Первый frame должен
быть полностью показан до обработки input и generation.

В core собственного unsafe нет. В ansa-linux std/rustix владеют descriptors,
poll, flags и termios. Узкие unsafe boundaries остаются для raw stdio duplication,
signal mask/signalfd и locale/wcwidth. Signals блокируются до workers; runtime и
writer завершаются до восстановления terminal flags и исходной signal mask.
Locale guard не оставляет thread-local locale активной между вызовами.

## Provenance, review и fallback

Captures сняты из clean `838f6bd`. Raw checker повторяет semantic assertions по
retained stdin/stdout, journal frames, actual HTTP requests и полным received SSE
bytes. PTY marks обязаны совпадать с raw prefix; operation IDs, incarnation,
tool outputs и Cancel связываются с canonical admission. Негативные controls
ловят пустые journals, подменённые кадры/IDs/results и неполный terminal body.

Два независимых review закрыты. Исправлены locale lifetime, aliased OFD restore,
drop ordering, HTTP EOF/header/trailer limits, CA FIFO, rejected draft, повторный
Cancel, oversized valid output и oneshot без Submit. Отдельно исправлены
обнаруженные false-PASS в evidence checker. Оба reviewers независимо повторили
M7 raw checker на итоговых clean captures; второй также повторил 32 negative tests.

Nix source proof сверяет 110 C++/harness и 100 Rust inputs. Для Debug/SAN full
suites 55 native C++ inputs не изменились относительно M6; CMake добавляет лишь
frontend oracle. Сам oracle заново собран в Debug и ASan/UBSan. Standalone Rust
binaries скопированы после final all-feature build; Cargo/Nix используют один lock.

Evidence, failed/superseded attempts, logs, binaries, source/handoff bundles,
source proof, hash manifest и GC-rooted Nix outputs сохранены в
`~/Workspace/pet/ansa-baselines/m7-838f6bd/`. Capture checkout:
`/tmp/ansa-m7-carbon-cli`. C++ fallback executable SHA-256 не изменился:
`420c80f7e7b9787e1b6eba18097f0ec97d3b25cc11630b4b0f1a840f88206ff0`.

Два намеренных отличия: self-check сообщает реальные Rust dependencies под
legacy field names; invalid UTF-8 argv отклоняется до создания session, тогда
как C++ может сначала напечатать session diagnostic. Контрольный сценарий
фиксирует оба результата, не ослабляя failure assertion.

Full access не является sandbox. Cancel не откатывает совершённый эффект;
неизвестный результат запрещает автоматический повтор. Fallback использует
последнее совместимое v1 state без возврата journal к старой копии.
Physical power loss, x86_64, live pilot, Rust sanitizers и performance budgets
этим milestone не закрыты. Performance и полный offline E2E относятся к M8.

## Воспроизведение

Из clean checkpoint внутри `nix develop --no-update-lock-file`:

```sh
cargo test --manifest-path rust/Cargo.toml --workspace --locked
cargo fmt --manifest-path rust/Cargo.toml --all -- --check
cargo clippy --manifest-path rust/Cargo.toml --workspace --locked --all-targets --all-features -- -D warnings
cargo build --manifest-path rust/Cargo.toml --workspace --locked --all-features --bins --examples
cmake --build build-ansa --target ansa_frontend_oracle -j 2
python tests/parity/run.py compare --suite frontend --cpp-build build-ansa --rust-target rust/target --output build-migration/M7
python tests/parity/run.py fault --suite frontend --cpp-build build-ansa --rust-target rust/target --output build-migration/M7-fault
python tests/parity/run.py check --milestone M7 --evidence build-migration/M7
```

budgets. Автоматически не начинать. Live pilot и cutover остаются закрыты.
