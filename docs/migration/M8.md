# M8 - полная offline-приёмка

Статус: **GO - offline gates пройдены**. Code checkpoint:
`50f016f` (ветка `migration/m8-offline-parity`, base M7 merge `dca0c64`).
Production/default остаётся C++20; Rust собирается отдельным `ansa-rs`.
M9, live credentials/calls, cutover и удаление C++ этим этапом не разрешены.

## Изменения

Полная offline-композиция соединяет production config/tools, Responses/SSE
admission, serialized runtime, canonical v1 journal и frontend. Проверяются
basic/plan, многошаговые turn, известный exit 7, compact, restart/Resume,
переключение C++/Rust в одном store и все durable crash boundaries.

Три изменения устранили выявленные расходы и задержки:

- JSON хранит immutable `Arc<Node>`, кеширует byte/node/depth bounds и пишет
  dump одним буфером. Exact number lexemes, duplicate/error priorities и
  ограничения logical expansion сохранены.
- Frontend ждёт readiness stdin/signalfd и writer notification. Явный yield
  после bounded input batch сохраняет Cancel при непрерывном TTY input.
- Session reducer проверяет candidate state до применения receipt delta.
  Replay больше не копирует весь исторический receipt index на каждой записи;
  ошибка не публикует частичное состояние, внешние snapshots остаются immutable.

Quality shell использует отдельный pinned nightly. Synthetic auth crash
завершается прямым Linux `exit_group`, чтобы моделировать аварийный выход без
перехваченных sanitizer atexit handlers; обычный runtime по-прежнему joins workers.
Исправлена также EOF/shutdown гонка: после закрытия input frontend больше не
посылает фоновые history queries; только уже отправленный внутренний read может
получить ожидаемый Closed. Ошибки пользовательских команд сохраняются.
Native regression удерживает generation 1200 ms и отправляет EOF во время
выполнения: старый код ошибается в обоих PTY modes, новый завершает durable
Done с exit 0.
Core не содержит собственного unsafe. Linux wrappers получили узкое независимое
review. Production dependencies, Cargo.lock (146 external packages), stable
toolchain и замороженные M0 budgets не изменены.

Используются одинаковые Release profiles и interleaved samples. Startup -
настоящие установленные CLI на одной canonical C++ истории 0/100/4096 submits;
20 observations на client/dataset. Первый complete frame и history-ready
совпадают: production показывает первый prompt после истории. Pipeline -
20 turn + 20 cancel observations на client/dataset; для hard cap измеряется
4096-й Submit из prefix 4095. Входные journal prefixes синхронизированы до clocks.
Preview fixture paced 800 ms одинаково для обоих клиентов; terminal→Done clock
начинается после admission и эту паузу не включает.

Safe CLI wall: warm 50/cold 20; GNU time RSS: 20/10. Controlled cold относится
только к executable pages, подтверждается mincore; dependency/filesystem caches
не объявляются cold. SSE - 20 samples по 50 admissions фиксированного stream;
отдельный malloc-family DSO run диагностический, без нового numeric ceiling.
Сборка: три own-target clean Release и девять entry-point incremental, `-j2`,
dependencies primed, single-process RSS и sampled descendants RSS каждые 20 ms.
Host power/governor/thermal/storage/toolchains/binary hashes сохранены до/после;
это измерения на общей пользовательской машине, не лабораторный SLA.

## Independent review и сохранение

- JSON reviewer: 28 329 old/new boundary comparisons и три новых adversarial
  tests; resource checker, actual Nix source binding и Release provenance.
- Runtime reviewer: readiness/ownership, continuous-input cancellation,
  scoped filesystem guards, raw clocks/process evidence, sanitizer crash
  semantics и transactional receipt delta.
- Shutdown reviewer: `50f016f`, весь frontend harness 34/34 PASS;
  origin tracking не скрывает Submit/Cancel/Resume/JSONL rejection.
- PTY oracle: независимо 10/10 actual captures PASS и 30/30 resealed mutations
  отклонены. Timeout pause, чужой Done и неверный target text не проходят.
- Performance checker: native positive controls, 12 resource tamper controls,
  24 maintained performance tests. Финальный полный raw replay подтверждён независимым reviewer.

Witnesses и логи: `checkpoint-reviews/`, `reviews-8771d06/`.
Полный raw performance replay повторён независимо от capture producer.

4096-submit journal (исправлен только bound evidence file, не production limits),
