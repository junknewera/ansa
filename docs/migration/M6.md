## Изменение

Rust сохраняет defaults и порядок user/project settings, exact base prompt,
AGENTS ancestry и instruction_token handshake. Существующий M4 catalog
используется без второго источника session state. Локальный registry содержит
list_directory, read_file, search_files, get_test_value и run_command с прежними
schema/revision; plan использует только четыре read-only tools. Сохранены
byte limits, правила binary/invalid UTF-8 и запреты protected/auth/session paths,
symlinks и hardlinks. Будущий auth root канонизируется через существующий prefix.

ProcessRunner пишет совместимые v1 request/started/result records с exact hash
и invocation/options. Чужой клиент читает результат и повторно использует его
без нового запуска. Consumed или ambiguous operation не исполняется повторно.
Обычный ненулевой exit — известный результат для следующего шага модели.
M5 runtime сохраняет результат и после адресной отмены.

Supervisor — fresh executable до Tokio/config/auth. Он сбрасывает унаследованные
signals, проверяет procfs/pidfd, устанавливает subreaper, очищает capabilities,
no_new_privs и null stdin. Ограничены output, timeout и cleanup; detached
descendants собираются после reap primary, чтобы не потерять adoption race.
После reap primary его старые PID/PGID больше не используются для signals.

В core нет собственного unsafe. Узкий ansa-linux boundary использует
clone3(CLONE_PIDFD), поскольку pinned stable std::process не предоставляет
стабильного атомарного pidfd ownership при SIGCHLD auto-reap. В child branch
подготовлены buffers/FDs; выполняются только syscalls и exec/_exit, без
allocator, locks или unwinding. Parent держит точный pidfd и join lifecycle
даже при ошибке wait. FD sources подняты выше stdio перед dup2.
