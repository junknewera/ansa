## Реализовано

- Bounded incremental SSE, strict owning JSON, lossless numeric tokens и legacy
  dump/hash; defaults совпадают с C++: body 16 MiB, line/event 1 MiB,
  arguments 256 KiB, items 64, calls 16, events 65536, depth 64, nodes 131072.
- Production request/Responses/native/replay builders. Continuation сохраняет
  исходный prefix, весь ordered native output, encrypted strings, matching
  call/results, requested/returned model и exact epoch/tools/account.
- Закрытые `AdmittedResponse` и `KnownBatchResults`, request/response-bound
  receipt, immutable registry snapshot, полная preflight-проверка batch,
  runtime operation IDs, consume-once `PreparedBatch` без Clone. Invalid response
  и invalid second call дают ноль pure counter executors. Отмена прекращает
  следующие dispatch, сохраняя известные результаты; unknown effect останавливает
  хвост и не создаёт replay.
- Saved response проходит synthetic SSE и тот же production semantic validator.
  Preview использует проверенный prefix; admission receipt создаётся после EOF.
  Derived calls следуют output index, даже если done events пришли в ином порядке;
  сами native arrays не сортируются.
- Frontend typed command/event contracts с version, typed IDs и cursor;
  runtime owner loop в этот этап не входит.
- Test-only C++/Rust adapters и independent raw-evidence checker. Проверяется
  полный request и continuation, а не только согласие двух implementations.
  Нельзя получить PASS пропуском cases, all-reject поведением, подменой binaries,
  argv, source, platform, raw bytes или ложным mutation marker.

По просьбе пользователя работу начали два native Luna исполнителя. Основной
агент завершил реализацию, исправления, проверку и handoff. Независимое ревью
проводили отдельные native `my-code-reviewer` и `security-auditor`.

## Corpus и safety assertions

Все семь C++ suites учтены по фактическим assertions, включая скрытые
streaming-preview проверки и parameterized loops. После C++ regressions:
`dependencies` 38, `sse` 2290, `reducer` 202, `replay` 37, `tools` 35,
`transport` 50, `contracts` 7 - всего **2659 runtime checks**. Это inventory
reference, а не требование одинакового числа assert-вызовов в Rust.

7303 compare cases включают обе fixtures, every split и bytewise/seeded
partitions, LF/CR/CRLF, BOM/UTF-8, strict JSON/limits/ownership, reducer identity,
metadata, terminal/EOF, replay, batch preflight и structured errors. Fault
содержит positive controls и нулевой executor oracle для отказов.

Девять настоящих localhost HTTP scenarios проверяют отправленный production
request и transfer до EOF: успешный control, interim response, duplicate/wrong
MIME, malformed charset, truncation после terminal и MIME trailers, включая
отсутствующий head MIME. В valid control запускается один pure counter executor;
после любого failed transfer - ноль. M1 localhost TLS/H2/proxy checks повторены.
Drop/reorder mutants меняют production Rust replay builder в отдельной копии
и падают на `native item count` / `native item order and values`; compile error
не считается пойманным mutant.

## Исправления по ревью

- JSON `with` повторно проверяет bounds; dump принятого custom-limit значения
  выше 16 MiB не паникует. SSE line default восстановлен до 1 MiB.
- Registry advertisement нельзя подменить через mutable snapshot; результаты
  batch связаны с полным admitted response. Panic validator даёт отказ до
  operation IDs и executors; registry/revision/run identities ограничены.
- Shared Responses validator проверяет mandatory argument target/type/lifecycle,
  initial/final arguments, полноту added/done items и content parts, response ID
  до 256 bytes и ранний call limit. Missing-created, wrong-model и invalid
  identity prefix не испускают preview. 11 дополнительных review regressions
  прошли на обеих реализациях; ранее корректный causal preview сохраняется.
- C++ network oracle использует production HttpHeadParser: trailer не может
  восполнить отсутствующий MIME в head. Test adapters отклоняют userinfo и
  нелокальные URL до соединения. Peer oracle сверяет весь request и отсутствие auth.
- Raw checker проверяет identities/argv/platform/exits, полный continuation
  и bounded regular files с NOFOLLOW/NONBLOCK. Symlink, hardlink, FIFO и oversized
  evidence отвергаются до чтения. Timeout regression допускает запуск Python
  под нагрузкой и сохраняет partial stdout/stderr.

Дополнительно обнаружен прежний C++ defect: `Json::at`/`elements` теряли явно
заданные bytes/depth/nodes при повторном разборе child. Теперь документ сохраняет
эти bounds и передаёт accessors. Добавлены ownership/large bytes/depth/nodes
регрессии; default limits и canonical writer не изменены. Test oracle builders
получили явный byte-limit parameter для больших synthetic envelopes.
Изменение production C++ прошло независимое ревью и всю native matrix.

## Воспроизведение

Все команды выполнять в pinned `nix develop --no-update-lock-file`.
Fresh output directories обязательны; существующие captures не перезаписывать.

```sh
cargo build --manifest-path rust/Cargo.toml --workspace --examples --bins --locked --features protocol-test-adapter
cargo test --manifest-path rust/Cargo.toml --workspace --locked
cargo fmt --manifest-path rust/Cargo.toml --all --check
cargo clippy --manifest-path rust/Cargo.toml --workspace --all-targets --locked -- -D warnings
cargo clippy --manifest-path rust/Cargo.toml --workspace --all-targets --locked --features protocol-test-adapter -- -D warnings
python -m unittest discover -s tests/parity -p 'test_*.py'
python tests/parity/run.py compare --suite protocol --cpp-build build-m2 --rust-target rust/target --output build-migration/M2-new
python tests/parity/run.py fault --suite protocol --cpp-build build-m2 --rust-target rust/target --output build-migration/M2-new-fault
python tests/parity/run.py check --milestone M2 --evidence build-migration/M2-new
ASAN_OPTIONS=detect_leaks=1 UBSAN_OPTIONS=halt_on_error=1 python tests/parity/run.py compare --suite protocol --cpp-build build-m2-sanitize --rust-target rust/target --output build-migration/M2-new-sanitized
python tests/parity/run.py check --milestone M2 --evidence build-migration/M2-new-sanitized --fault-evidence build-migration/M2-new-fault
```

CMake/native CTest commands - в README. Nix default остаётся C++, дополнительный
Rust package собирается `nix build --no-update-lock-file .#ansa-rust`.

## Следующий этап и ограничения

M2 закрывает offline protocol/replay и pure admission. Новый Rust runtime,
auth/OIDC, durable executors, journal, owner loop, UI, automatic retry и live
model calls сюда не входят. JSON optimization и ранняя Release latency-оценка
отложены по явному решению пользователя; performance parity не заявляется.
Следующая отдельная задача - M3 synthetic auth/OIDC и совместимый store v1 по
плану. Она не начата этим checkpoint.
