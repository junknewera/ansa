# M2 - protocol, Responses, replay и batch admission

Статус: **WIP / NO-GO**. Последний проверенный Rust milestone - M1,
base `e1b47848b81ec6ef97949a68989fcada8937c644` (merged PR #4).
Production executable и Nix default остаются C++20. Этот документ не подтверждает
реализацию или прохождение gates до появления фактического closeout.

## Согласованные решения

- Один итоговый PR после полной приёмки; промежуточные checkpoints являются WIP.
- Оптимизация JSON и ранняя Release-оценка её стоимости отложены. Проверки
  byte/depth/node/count limits относятся к корректности и остаются обязательными.
- Tools разрешаются только после успешного полного HTTP response и проверки
  всего batch. Admission и подтверждение transport EOF связаны с конкретным
  owning request/exchange, закрытые типы нельзя создать публично или Deserialize.
- Saved response проходит synthetic SSE и тот же production decoder. Второй
  final semantic validator в M2 не вводится.
- Request JSON сравнивается структурно. Arrays/native item order, number lexemes,
  encrypted strings и provenance сохраняются точно; legacy dump/hash - побайтно.
- Низкоуровневые Rust API выбирает исполнитель. PreparedBatch consume-once,
  не Clone; operation IDs присваивает runtime/factory.

Пользователь поручил начальную реализацию двум native Luna исполнителям,
затем передал завершение основному агенту. Основной агент исправляет review
findings, выполняет native checks и итоговый handoff. Новые model
capabilities, auth, real model requests, durable tools, journal, runtime owner,
UI и automatic retries не входят в M2.

## Corpus и критерии

Все семь suites `tests/protocol_tests.cpp` обязательны. Одни CTest IDs не
доказывают перенос: нужен inventory внутренних assertions и параметрических
loops с одинаковыми accepted/rejected outcomes и независимыми safety assertions.
Пример regex в плане исправлен: теперь включает `dependencies`.

Исходный C++ Debug baseline на X13s выполнен: **7/7 suites, 2655 runtime checks**
(`dependencies` 35, `sse` 2289, `reducer` 202, `replay` 37, `tools` 35,
`transport` 50, `contracts` 7). Это reference исходного поведения, не Rust PASS
и не требование одинакового числа assert-вызовов при другом устройстве тестов.

| C++ suite | Обязательные проверки |
|---|---|
| dependencies | Strict JSON/UTF-8/decoded duplicate keys, limits, unsigned indices, number lexemes, owning lifetime и structured errors; platform/dependency smoke отдельно от portable semantics |
| sse | Every split, bytewise/seeded partitions, BOM/UTF-8/CR/LF/CRLF, multiline data/reset, partial EOF, limits, poisoned/reused stream |
| reducer | created/sequence/item/call/model consistency, text/delta/final-only args, native opaque items, metadata, unknown events, terminal/EOF, скрытые streaming_preview assertions |
| replay | Production serialized continuation, исходный prefix, все native items и matching outputs; exact epoch/tools/account; результаты и operation IDs |
| tools | Whole-batch validation, invalid second call -> 0 executors, consume-once, cancel, immutable snapshot/schema; unknown/invalid outcome останавливают хвост, known outcomes сохраняются по контракту C++ |
| transport | MIME/status/headers/trailers/limits и narrow SIWC policy; настоящий reducer+batch counter на transfer failure после terminal |
| contracts | Закрытое создание admission, noncopyable batch, разные typed IDs; frontend command/event version и cursor/sequence без runtime loop |

Обе fixtures `round1.sse` и `round2.sse` сохраняются. Drop/reorder mutants должны
менять production replay builder и падать на конкретной safety assertion;
ошибка компиляции не является killed mutant. M1 probe `executors:0` сам по себе
M2 admission не доказывает: нужны реальные pure counter executors.

## Требуемый closeout

- Реальные compare/fault `--suite protocol` и `check --milestone M2` с raw
  stdin/stdout/stderr, failures/timeouts, source/fixture/binary identities,
  exact inventories и повторной semantic проверкой retained outputs.
- Rust locked workspace build/test, fmt, clippy, Nix package и feature audit;
  M0/M1 harness regressions сохраняются.
- Production entry point, полный native C++ Debug/Release CTest, adversarial
  tests и ASan/UBSan с `--output-on-failure --no-tests=error`.
- Независимое ревью, исправления с регрессиями, clean checkpoint и evidence
  preservation; затем обновление PROJECT_STATE с проверенным SHA.

Точные counts, actual commands, results, review findings и непроверенные gates
будут записаны по результатам выполнения. Пока M2 остаётся NO-GO.

## Review и обнаруженные дефекты

Первый независимый read-only review JSON/SSE выявил два дефекта Rust: `with`
создавал объект без повторной проверки общих bounds, а `dump` мог паниковать
на значении, успешно принятом с custom byte limit выше 16 MiB. Исполнитель
исправил оба случая и добавил регрессии; повторный source review подтвердил
исправления. Динамическое исполнение регрессий входит в общий pending gate.

Большой positive case также выявил существующий C++ defect: `Json::at` и
`elements` повторно парсили дочернее значение с default limits, теряя явно
заданные родительскому документу bounds. Разрешён узкий production fix:
документ сохраняет bytes/depth/nodes, accessors используют ту же тройку.
Global defaults остаются 16 MiB/64/131072; canonical writer не меняется.
Добавлены C++ regression checks для больших bytes, depth и nodes, включая
владение значением после уничтожения parent. Review и full native gate
для этой правки ещё выполняются. Старый M1 C++ fallback сохранён; новый
C++ executable после этого исправления может иметь другой SHA-256.
