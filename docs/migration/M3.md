# M3 - auth/OIDC и совместимый store v1

Статус: WIP / NO-GO. Base - merged M2 `62b6027` (PR #5).
Последний проверенный Rust milestone остаётся M2. Production/default - C++.

Scope: signature/claims, discovery/registration, PKCE, loopback callback,
refresh/login/logout state machines, v1 private store, shared process lock,
atomic replace/fsync, execution lease и lazy dispatch guard. Все fixtures и
exchanges синтетические; реальные credential stores не используются.

Acceptance: все 16 auth suites C++ с фактическими assertions, C++/Rust
read/write/reopen в обе стороны, один concurrent refresh, durable pending до
POST, отсутствие повтора ambiguous exchange, logout marker до ожидания lease,
закрытие watcher/join при отмене и после удаления manager. Дополнительно JWT/RSA,
callback, file permissions/link/owner/FIFO и crash-boundary adversarial cases.

Проверки: native C++ Debug/Release/ASan+UBSan, locked Rust build/test/fmt/clippy/Nix,
compare/fault --suite auth и raw replay checker, регрессии M1/M2, независимые
reviews, Git checkpoint, evidence и один итоговый PR. Фактические результаты и
отдельно reviewed deviations будут внесены после исполнения; этот файл не GO.

Новые зависимости: oauth2 5 с default-features=false для PKCE, base64 0.23;
без второго HTTP/TLS client. Реальный agent bootstrap/live auth, journal,
owner loop, UI, multi-profile и cutover не входят в M3.
