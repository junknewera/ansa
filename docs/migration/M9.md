# M9 - bounded live acceptance и обратимый cutover

Статус: WIP, GO не заявлен. Base: merge PR #13 `9e6e6de`.

Пользователь в текущей сессии разрешил продолжить ранее предложенный M9,
если local-harness-benchmark ещё рано использовать. Проверка исходников стенда
подтвердила: подготовлены задачи/evaluator, но runner и adapter ansa отсутствуют.
Изменение benchmark и внешние Codex/Claude прогоны в M9 не входят.

## Согласованная live-граница

- Текущий собственный профиль ansa и неизменные client/account/session binding;
  модель `gpt-6.1-sol`. Реальный store открывает только production executable.
- Всего не более 12 generation/summary requests. Перед каждым из трёх процессов
  с единственным Submit сохраняется невозвратный резерв 4 requests: максимум
  2 tool rounds + final generation и одна возможная pre-Submit compaction.
  Проектная конфигурация проверяется через production `--print-config` до сети.
  Resume, дополнительные Submit и автоматические повторы не выполняются.
  Служебные auth/catalog HTTP-запросы не являются model requests.
- Тестовый каталог `/tmp/ansa-m9-*`: read_file, безопасная foreground-команда,
  durable Done; restart/continue без повторения tools; адресный Cancel команды
  с задержкой, known cancelled outcome, восстановление termios и restart.
- Одна явная `--refresh-auth` и штатное обновление при работе; без logout/login.
  При отсутствии текущей авторизации прогон останавливается.
- C++ fallback открывает самую свежую завершённую сессию без Submit; journal
  bytes должны сохраниться. Credentials/journal backups не откатываются.

## Проверки и выбор пакета

До live повторяется полный offline `compare --suite e2e` на точном clean code SHA.
Production core/providers/tools/session codecs не меняются. Проверяются native
workspace, frontend, locked pins, Nix packages и независимый review.

В ветке подготовлен выбор Rust release candidate по умолчанию: `nix run .#`,
aliases `ansa`/`ansa-rs`. `nix run .#ansa-cpp` сохраняет C++ fallback, а
`.#ansa-rust` остаётся совместимым явным выбором Rust. Глобальная установка и
переключение пользовательского shell не выполняются. Удаление C++ - только M10.
При провале live/default не объявляется GO; PR не выдаётся за принятую миграцию.

Результаты и checkpoint будут добавлены после фактических проверок.
