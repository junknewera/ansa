## 2. Что умеет harness сейчас

`tests/parity/run.py` — один stdlib script для M0, без scheduler, plugin hooks, framework или внешних Python packages.

- `preflight`: запускает отдельный Linux probe и actual toolchain checker, сохраняет оба результата даже при failure первого.
- `capture`: записывает source/fixture/binary hashes, platform, CMake options, versions, actual argv/exit/timeout/time и отдельные exact-byte stdout/stderr. Выполняет только safe CLI forms; получает actual CTest inventory. Полный существующий CTest запускает только при `--run-ctest`, сохраняет raw JUnit и фактические case results.
- `check --milestone M0`: проверяет recorded inputs/output digests, binary/probe identity, CLI semantic assertions, exact CTest IDs, failures/skips, preflight и native platform. Проверяет один capture; не объявляет весь M0 GO.
- `compare`, `fault`, `perf`: **UNIMPLEMENTED, exit 2**. Нового protocol comparator, fault scheduler и benchmark runner нет. Без `--run-ctest` CTest остаётся NOT_RUN и не проходит evidence gate.

Manifest фиксирует existing 87 IDs и два SSE fixtures. Sanitizer child profile исключает ровно два mutants и требует 85 IDs. Missing/duplicate/skipped/disabled/failed cases не проходят. [Команды и формат](../../tests/parity/README.md).

### Actual toolchain compatibility

`rust/rust-toolchain.toml` channel и workspace MSRV — **1.98.1**, Edition **2024**. В pinned Nix shell реально запущены:

- `rustc 1.98.1 (48a229cea 2026-09-01) (built from a source tarball)`;
- `cargo 1.98.0 (797e8a9bc 2026-08-05)` из Nix derivation `cargo-1.98.1`.

Это ожидаемое различие Cargo patch и package/toolchain label. Checker требует exact compiler pin, stable Cargo той же major/minor серии и успешный `cargo metadata --offline --locked --no-deps` с обоими Edition/MSRV. Он проверяет реальные paths/versions; не выводит версию Cargo из имени Nix package и не разрешает rustup автоматически скачать toolchain. Checker также выполняется в Nix Rust `preBuild`.
