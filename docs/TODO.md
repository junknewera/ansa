## Согласованный Carbon UX

Эталон - `designs/final-design/`, с исправлениями файлового Preview из PNG `-3`.
Новый интерфейс заменяет обычный интерактивный Carbon по умолчанию; one-shot,
pipeline, JSONL и NO_COLOR сохраняются. Согласованный этап реализован;
результаты и checkpoint - в [PROJECT_STATE](PROJECT_STATE.md).

- Основной экран: чат, закреплённый ввод, реальные этапы и время задачи.
  Inspector открывается по необходимости; на узком терминале расположен под чатом.
  Диалог прокручивается мышью. Печать сохраняет позицию чтения, а после
  подтверждённой отправки Enter показывает последние сообщения.
  Esc возвращает последние сообщения, следующий Esc в дочернем чате - родителя;
  в файлах Esc возвращает чат, в меню - закрывает без применения. Выделение текста автоматически копируется при отпускании
  кнопки мыши; обновления не сдвигают выделяемый текст.
- Новое сообщение во время reasoning или tool сохраняется и передаётся модели
  сразу после текущего шага, до следующего действия, без ожидания окончания всей
  задачи. `Ctrl+C` очищает черновик, а при пустом вводе прерывает текущий шаг.
  Два нажатия в свободном чате закрывают ansa. Известные результаты сохраняются,
  storage failure и неизвестные эффекты по-прежнему запрещают новый dispatch.
- `/model` открывает кэш каталога и обновляет его в фоне. Выбор модели открывает
  effort; Enter применяет пару, Esc возвращает список моделей. `/effort`
  (`/thinking` - алиас) меняет уровень отдельно. Выбор сохраняется в сессии.
- `/` в начале любого слова открывает подсказки над вводом. Стрелки выбирают,
  Tab или → дописывают команду. Enter сразу выполняет полную команду в начале
  ввода. `?` в пустой строке открывает помощь:
  одна команда с описанием в строке. Внутри сообщения команды остаются текстом.
- Фон берётся из терминала; тема задаёт акценты и цвета текста. Таймер,
  этап и анимация работы расположены в диалоге. `ANSA_NO_ANIMATION=1` отключает
  анимацию. Ожидающее уточнение выделяется приглушённым маркером.
- Подробности инструментов показывают аргументы и текст результата с переносами.
  Полный вывод открывается в той же боковой панели; Esc возвращает прежний вид.
- `/new` открывает пустой разговор в текущем проекте. `/resume` открывает `/sessions`.
- `/agents` показывает дерево помощников текущего main/fork с названиями задач,
  включая завершённых и запущенных через `/btw`. `/sessions` показывает основные
  разговоры и ветки по заголовку и фрагменту, без технических ID в списке.
- `/btw` - отдельный побочный разговор с подтверждённым контекстом и read-only
  tools; передача результата основной задаче только явным действием.
  `/fork` - отдельная независимая сессия с тем же контекстом и рабочей папкой.
- Реальные субагенты разрешены по прямой просьбе пользователя либо явному
  указанию применяемого скилла. Самостоятельный выбор режима не является
  разрешением делегировать. Свои чаты, возврат к родителю и передача результата.
- Read-only Source, Diff относительно Git HEAD и Markdown Preview. Внешний
  `$EDITOR` открывается только при остановленном/завершённом агенте.
  `q` в `/files` открывает одну сохраняемую сессию shell в той же панели.
  В zsh Esc из приглашения возвращает файлы в текущем каталоге shell; в Vim
  сначала `:q`, затем Esc. Ctrl+C относится к программе терминала.
  `/run` убран. Ручные команды и их вывод не добавляются в контекст агента.
- Поиск слов по истории исключён по решению пользователя. История сообщений,
  прокрутка и выбор сохранённых сессий остаются. Бинд `Ctrl+F` и подсказки
  `PgUp`/`PgDn`, `Ctrl+F`, `↑`/`↓` удаляются; сами клавиши навигации остаются.

Матрица проверена по первичным документам 2026-11-15:
